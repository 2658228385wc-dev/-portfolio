# 换图说明（含实测尺寸）

把图片按下面的**文件名**命名，丢进本目录，构建即生效。不需要改任何代码。
扩展名随意（`png` / `jpg` / `webp` / `avif` / `gif`），**只认文件名**。

> 支持「本地优先」：没放的文件自动回退到远程原图，可以一张一张慢慢换，中途不会出现破图。

## 3. 横向滚动区（8 张）— ✅ 2026-10-20 已减至 8 张并替换

当前文件 `marquee-01.webp` … `marquee-08.webp`：**960×540 WebP q88**，合计约 505 KB。

规格与展示关系：

- 图块按 **16:9** 展示：移动端 391×220、桌面 480×270，宽度由比例从高度推出，**不会裁切**。
- 出图标准：**16:9、960×540、WebP q85–90**，20–180 KB/张。源图多大都可以，等比缩到 960 宽即可。
- 顺序即展示顺序：前 4 张走第一行，后 4 张走第二行（三倍循环滚动）。
- 若想恢复原来的远程 GIF：删掉本目录的 `marquee-*.webp` 再构建即可（或跑 `npm run images:pull -- --force` 重新拉远程）。

## 换图操作

**手动**：文件按名字放进来 → `npm run build`（或开发时 `npm run dev` 热更新）。

**批量拉到本地再覆盖**：`npm run images:pull`（`-- --force` 强制重下，会覆盖本目录同名文件）。

**交给我做**：把原图放任意目录丢给我，我负责裁切、压到目标体积、按名重命名、替换、重新构建并截图验收。
